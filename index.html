      記録のバックアップ

      記録はこのブラウザの中に保存されます。スマホを替える前や、ブラウザのデータを消す前に書き出しておくと安心です。

      GitHubに置くとき

      このアプリは index.html 1ファイルだけで動きます。下のボタンでこのファイル自体を保存して、リポジトリに置けばそのまま使えます。GitHub Pagesを有効にすれば、URLで開けるページにもなります。

      手順の目安

      1. GitHubで新しいリポジトリを作る（Public）
2. index.html をアップロードして Commit
3. Settings → Pages → Branch: main / (root) を選んで Save
4. 数分後に表示されるURLを開く

      ※ GitHub Pagesで開いた場合も、記録は「開いているブラウザ」に保存されます。別のブラウザで開くと記録は別になります。
